# [Emri i shkollës]: faqja e internetit

Static site for the school building, built with Jekyll and hosted on GitHub Pages.

Read `HOUSE-STYLE.md` before making changes. It covers publishing, writing, images, the English version and the domain switch.

## First-time setup

1. Create the GitHub organisation and add at least two owners.
2. Create a public repository named `[org-name].github.io` and push these files.
3. Settings → Pages → Source: deploy from branch `main`, folder `/ (root)`.
4. Replace every `[BRACKETED]` value. Start with `_config.yml` and `_data/info.yml`.
5. Delete the sample post in `_posts/` and its image.

To find leftover placeholders: search the repository for `[`.
